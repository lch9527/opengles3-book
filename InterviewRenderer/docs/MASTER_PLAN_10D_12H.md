# Tesla Rendering Interview Prep (10 Days, 12h/Day)

Total budget: `60 hours`
Cadence: `5 days/week`, `12 hours/day`, `2 weeks`
Platform focus: `Linux + C++ + OpenGL ES 3`

## Goal

Build your own C++ OpenGL ES renderer from this repo, with interview-ready evidence in:

- real-time rendering techniques
- GLSL depth
- 2D/3D rendering architecture
- GPU/CPU optimization workflow
- code quality and maintainability

## Structure

- Week 1 execution: `docs/WEEK1_5DAY_12H_CHECKLIST.md`
- Week 2 execution: `docs/WEEK2_5DAY_12H_CHECKLIST.md`
- Project scaffold: `InterviewRenderer/`

## Daily output requirement

Every day must end with:

1. runnable code snapshot
2. 8-15 bullet learning notes
3. metrics log (`FPS`, `frame ms`, `draw calls`, key issues)
4. short next-day task list

## End-state acceptance

- `InterviewRenderer` runs on Linux/X11 through WSL2
- includes shader management + render loop + resource wrappers
- includes lighting + post-process pass
- includes optimization report (before/after)
- includes concise README + interview story bank
